# 研发路线

本仓库采用“可重复基线 → 多模态模型 → 独立批次盲测 → 生产化”的路线。

## Phase 0 — 数据工程

1. 固定采集协议并记录 device_id / protocol_id。
2. 建立暗参考、透射参考、ROI 和波长元数据链。
3. 按 egg_id 做整样本隔离；按 batch_id 做批次隔离。
4. 保存原始数据，所有增强只作为派生数据。

## Phase 1 — 可解释基线

同时训练 spectral-only、RGB-only、fusion 三个分支。比较 AUC、balanced accuracy、Brier、coverage 和按批次表现，而不是只看单一 accuracy。

## Phase 2 — 深度模型

当 Phase 1 证明数据具有稳定信号后，再引入轻量 CNN/ViT 图像分支、1D spectral encoder，以及 late-fusion / cross-attention。所有模型保持同一 train/val/calib/test 契约。

## Phase 3 — 可解释性与消融

加入 Grad-CAM 或 attention rollout，并做背景遮挡、主体遮挡、随机标签、跨设备和跨批次实验。热图只能作为诊断工具，不能作为生物学机制证据。

## Phase 4 — 生产化

冻结模型、阈值和特征 schema；建立拒识区间和复检通道。再做新批次盲测、跨设备验证、覆盖率评估、模型导出和推理延迟测试。

## 关键原则

- 不使用 test 调参。
- 不把重复观察当成独立样本。
- 不把合成数据结果写成真实性能。
- 不把公开代码或权重直接视为可商用。
- 生产模型必须有版本号、配置哈希、数据契约和可追溯推理日志。
