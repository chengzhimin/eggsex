# 科研路线（v0.2修订）

当前目标是建立可复现的鸡胚性别预测研究，不以生产验收为研究前置门槛。

1. 核查成像、参考校正、egg_id和性别真值；保留失败样本及原因。
2. 并行比较光谱统计模型、1D光谱CNN、ResNet18和融合，不要求先用SVM证明有效才研究深度模型。
3. 开展批次外层验证；预先定义RGB/G/CLAHE、光谱/图像/融合、随机初始化/迁移学习对照。
4. 用配对预测、批次bootstrap、标签置乱和混杂对照评价；将最终盲测与开发CV分开。
5. 按结果引入区域光谱、HSI patch、多实例学习、3D-CNN或Transformer，不凭网络复杂度判断优劣。
6. 通过空间遮挡、区域标注和独立样本的分子数据提出机制假设；热图和预测增益本身不能证明机制。

详见[全面科研评估](科研评估_v0.2.md)。生产设备接入可作为后续独立工程任务。
