# 鸡胚 E3.5–E4.0 图像与高光谱性别预测：系统科研评估

日期：2026-09-05。评估对象为 chengzhimin/eggsex 的 v0.1 基线、相关公开研究及本次 v0.2 实现。尚无本项目真实鸡胚数据，因此本文给出方法学审查、模型选择依据和可执行评价流程；不报告虚构的真实性能排名。

## 1. 科研问题应怎样定义

可以并行研究传统模型和深度模型。研究目的首先是估计：在给定品系、胚龄、成像条件下，RGB、HSI及其联合输入的预测能力能否在独立鸡蛋和新批次中重复。当前不需要将生产复检率、机械节拍或设备验收设为开始建模的条件。

建议预先定义三个层次的假设：

1. **预测关联**：某种输入在未参与训练的鸡蛋上优于适当的机会/基线水平。
2. **增量信息**：HSI+RGB对同一批鸡蛋的预测优于单模态，且该差异跨批次稳定。
3. **机制解释**：与性别相关的组织、生理或分子差异解释了有效表型。它需要独立的生物学数据及适当设计，不能从前两个结论直接推出。

“融合准确率高于RGB”也可能受到参数量、训练策略和批次混杂影响。需比较等训练预算、单分支容量对照、随机配对/缺失分支等实验。照片中的注意力图只能提出区域假设。

## 3. 旧版代码的具体问题与修订

| 旧版情况 | 本次处理 |
|---|---|
| “RGB模型”仅35个颜色/梯度统计量 | 加入直接学习图像的ResNet18，同时保留统计基线 |
| HSI统计特征拼接后只有SVM | 新增1D CNN，以及光谱/图像双分支融合 |
| 只有固定一次数据划分 | 传统模型嵌套批次CV；深度模型外层批次CV；可多种子 |
| 把验证准确率区间用于默认复检门槛 | 科研默认阈值0.5；选择性分类改为可选，不删掉低置信度有效样本 |
| 逐蛋Wilson区间未处理批次相关性 | 增加批次bootstrap和配对准确率差异区间 |
| 模态间可能比较不同QC人群 | benchmark/deep-cv内使用共同有效队列并输出排除清单 |
| 缺少标签置乱 | 传统模型可批次内置乱并完整重跑嵌套流程 |
| preview导入了不存在的rgb_features | 修正为实际image_features |
| 配置的胚龄边界未用于输入检查 | 配置age_min_h/age_max_h时检查age_h；不配置时不冒称限定胚龄 |

未解决的问题也需明确：当前仍使用一蛋一个观察；HSI只取ROI汇总谱，不等于完整高光谱空间建模；没有自动血管分割、Grad-CAM、分子机制验证。v0.2是可训练研究框架，不是对某篇论文的逐行复现。

## 4. 为什么换成这些模型

| 候选 | 合适用途 | 当前定位 |
|---|---|---|
| Logistic/PLS-DA/SVM/Extra Trees | 样本量有限、光谱高维共线、建立可核对基线 | 四类均实现，参与相同分组评估 |
| 1D光谱CNN | 学习邻近波段模式；参数少于大型Transformer | 已实现；输入为3×B统计谱，不含每像素空间位置 |
| ResNet18 | 从图像直接学习纹理/形状；提供成熟迁移学习对照 | 已实现，随机初始化或ImageNet初始化可选 |
| 双分支CNN+ResNet18 | 不要求像素级配准的逐蛋联合预测 | 已实现；特征拼接+MLP，是合理起点，不宣称最优 |
| MobileViT/ConvNeXt/更大ViT | 增加图像架构对照 | 下一阶段；需控制分辨率、训练预算和初始化来源 |
| HybridSN类3D–2D CNN | 从HSI patch学习空间与光谱联合特征 | 候选；需重构蛋级聚合与数据管线 |
| SpectralFormer/EggFormer | 研究局部或长程光谱关系、空间光谱交互 | 候选；不能沿用遥感像素随机切分方式 |

ResNet18使用[Torchvision官方模型](https://docs.pytorch.org/vision/stable/models/generated/torchvision.models.resnet18.html)，ImageNet权重只提供图像表征初始化，不包含鸡胚性别知识。[HybridSN原始代码](https://github.com/gokriznastic/HybridSN)使用3D与2D卷积结合；[SpectralFormer作者代码](https://github.com/danfenghong/IEEE_TGRS_SpectralFormer)提供高光谱Transformer实现。这些公共模型的主要实验领域与鸡胚不同，需要重新训练和评价。

[EggFormer作者地址](https://github.com/quietbamboo/EggFormer)由论文给出，本轮未成功读取其仓库内容；不将它写成已经可运行的依赖。[LSCI公开仓库](https://github.com/anika24/lsci-egg-sex-classification)适合研究复现与负对照，但其成像模态不能冒充HSI。

**选择建议**：主线先比较1D CNN、ResNet18、双分支融合与四类传统模型，不需要先证明传统模型有效才能训练深度模型。当汇总谱明显损失空间信息且数据量允许时，再做HSI patch/多实例学习。网络更复杂不自动构成论文创新。

## 5. 采集与预处理审查

保留原始DN、实际波长、曝光/增益/bit depth、暗参考及透射参考。校正分母过小或饱和时标记失效；不能把异常值统一裁到0–1后当成正常光谱。光谱分支不逐波段CLAHE。

KG3/KG5不能简单理解为只截断1200nm以上；需结合厚度与实际透过曲线评估有效近红外信号，见[SCHOTT原厂数据表](https://media.schott.com/api/public/content/ff5709047dd541d791006baf6c50e675?v=a70fb460)。540/575nm与“绿色通道最佳”应作为候选假设，不能取代实测信噪比及跨批次验证。SWIR设备不能生成其未测量的可见波段。

RGB比较原RGB、G、G+CLAHE；CLAHE参数需结合输入尺度固定。本版为网络输入做保持比例的裁切/补边；高分辨率微血管可能在224像素下损失，需要比较更大输入或局部patch，不能把224视为最优。

当前人工复核mask是合理起点；后续可标注胚体、血管和非血管区域。RGB/HSI特征级融合只要求同蛋配对；像素级交叉注意力必须先处理几何配准与采集时差。

## 6. 数据设计与评价层次

**独立单位是鸡蛋。** 重复拍摄应全部归属于同一个egg_id；不能随机将同蛋视角分到不同集合。v0.2仍要求清单每蛋一行，便于先检验可重复性。后续多时点研究应明确E3.5、E4.0单时点与纵向联合输入的不同问题。

记录但不默认直接送入性别模型的混杂字段：品系、壳色、蛋重、种鸡群/周龄、储存天数、胚龄小时、孵化器、采集日期、操作者、曝光与光源。不要先知道性别再分别采集；标签需独立确认。未孵化、图像失败和标签缺失样本应保留原因，避免仅分析成功出雏鸡蛋造成选择偏倚。

样本量不由图片总张数决定。先做光路和重复性试验，再根据目标置信区间、批次差异和学习曲线追加独立鸡蛋与批次。增加批次数往往比只在同批重复拍摄更能检验泛化。本文未给出未经功效计算的固定“足够样本量”。

分三层评价：

1. **固定划分探索**：train拟合、val早停、calib校准。快速发现数据/模型问题。
2. **开发集批次CV**：合并开发部分，外层按batch_id留出。传统模型在外层训练折内调参和分组校准；深度模型在其中再分拟合、早停、校准。所有模型均不打开最终test文件。
3. **最终盲测**：选定模态、架构、预处理及训练策略后，再评价未参与选择的新批次。若根据盲测继续调参，该集合就变成开发数据，需要新的最终评估。

实现参考：[分组交叉验证说明](https://scikit-learn.org/stable/modules/cross_validation.html)及[置乱检验的分组含义](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.permutation_test_score.html)。本项目显式构造折，避免SVM内部不受控的随机图像级概率校准。

## 7. 建议的消融与对照矩阵

| 维度 | 对照 | 当前自动化状态 |
|---|---|---|
| 输入模态 | HSI / RGB / 联合 | 已实现 |
| 图像预处理 | RGB / G / G+CLAHE | 已实现；分别运行，比较同蛋 |
| 初始化 | 随机 / ImageNet / 冻结图像编码器 | 已实现 |
| 模型 | 四类传统 / 1D CNN / ResNet18 / 融合 | 已实现 |
| 标签 | 真标签 / 批次内置乱 | 传统嵌套流程已实现；深度完整置乱未实现 |
| 区域 | 全ROI / 胚体 / 血管 / 非血管 | 需不同人工或验证后的mask，未自动生成 |
| 联合信息 | 正确同蛋配对 / 同批随机错配 / 零化分支 | 尚需专门实验；不可把置零造成的分布外输入直接解释为因果 |
| 混杂 | 仅元数据 / 仅蛋壳背景 / 仅曝光亮度 | 尚需数据字段与区域标签 |
| 泛化 | 新批次 / 新品系 / 新设备 | 批次评估已实现；多设备配置与域迁移尚需适配 |
| 数据量 | 学习曲线，逐步增独立鸡蛋/批次 | 尚需真实数据执行 |

不要一次搜索大量参数后只报告最优一项。预先限定候选范围，保存所有运行配置、随机种子和失败结果；探索与确认分析在论文中分开。

## 8. 怎样报告结果

主要指标可预设为逐蛋AUC或平衡准确率。同时报告M/F各自召回率与精确率、Macro-F1、MCC、Brier、混淆矩阵、有效输入比例。普通科研分类报告全部有效输入的结果，不因低置信度剔除难样本。

同蛋配对比较必须按egg_id对齐。v0.2给出准确率差A−B及批次bootstrap区间；只有一个批次时不计算批次区间。现有区间基于固定预测，不能覆盖重新训练的全部不确定性，也不校正挑选最佳架构的偏差。重复CV种子不增加独立样本数。

标签置乱在批次内部进行，以保留批次与类别构成。每个批次仅有单一性别时，这种检验无信息，应修改采样设计；不能以跨批全局置乱掩盖批次与性别完全混杂。多个模型/模态的p值需要预设主比较或进行多重检验处理，当前代码不自动校正。

**可写的结论**：“在指定条件与独立批次中，模型获得某区间的预测性能，联合输入相对某单模态提高多少。”

**当前不能写的结论**：“E4任意品种均可准确鉴定”“注意力证明血管是性别决定机制”“合成数据高准确率证明模型有效”。

## 9. 当前交付及下一步

已交付科研分类模式、三种深度模型、四种传统对照、两类批次CV、配对比较和测试。真实权重训练、真实性能排名、自动解释图和分子关联尚未完成。

最小接入资料仍是设备型号、原始HSI及暗/透射参考、同蛋RGB、egg_id与性别真值。可以先用少量样本核对格式；模型效能评估需要独立多蛋多批次数据。会议照片可用于讨论流程，不能替代原始高光谱或构造性别训练集。
